# 🪟 彩绘玻璃拼片台（Stained Glass Bench）

为彩绘玻璃工作室设计的网页拼片台：输入矩形窗框的正整数毫米宽高，在画布上以
**整数毫米坐标**绘制带编号和颜色的多边形玻璃拼片，系统实时做几何校验、缺口分析，
并在发布时生成各片面积报告与**铅条下料清单**。

技术栈：**Node.js + Express + better-sqlite3**，前端为零构建原生 HTML/JS Canvas。

## 功能说明

### 拼片编辑（草稿）
- 新建窗框时输入**正整数毫米**宽、高（拒绝非整数/非正数）。
- 在画布上逐点点击绘制简单多边形；支持整数网格吸附，并优先吸附到现有拼片顶点
  （便于沿 T 形接头精确拼接）。点击拼片可重画，也可单独改颜色/删除。
- 每个拼片自动获得顺序编号与颜色。
- 每次新增/修改都在服务端做几何校验，**以下编辑会被拒绝并返回具体位置
  （前端在画布上红点脉冲标注）**：
  - 自交（边穿越、非相邻边重叠、面积退化）；
  - 越界（顶点落到窗框矩形之外）；
  - 与现有拼片发生**面积重叠**（边穿越、顶点落入对方内部、凹多边形覆盖、完全重合）。
- 允许拼片以边相接：T 形接头、顶点接触、共线公共边均可；尤其支持
  **公共边一侧为整边、另一侧为数段**的情形。

### 覆盖检查与发布
- 编辑过程中随时计算未覆盖区域，画布以**红色斜纹标出缺口多边形**并给出缺口总面积。
- 只有拼片**完整覆盖窗框且无空隙**时才能发布；否则返回 422 与缺口区域坐标。
- 发布版包含：每片的编号、颜色、面积（mm²）、总面积（应等于窗框面积）。

### 铅条下料清单
- **公共边无论被分成多少段、跨越几片，都只计一次**：以每条边所在“支撑线”分组，
  同一直线上的共线段先做区间并集（`A x + B y + C = 0` 归一化后按方向参数合并）。
- **外框（上下左右四条）单独列出**。
- 长度逐条精确求和，**最后统一四舍五入到 0.01 mm**（斜边为真实长度，
  如 10 mm 的 45° 对角线记 14.14 mm）。

### 版本管理
- 发布后生成不可变版本（v1、v2…），快照包含图纸与铅条清单。
- **后续编辑与清单重算只作用于草稿**；历史发布版可随时查看，内容永不改变。

## 快速开始

### 方式一：Docker Compose（推荐，一键启动并初始化数据库）

```bash
docker compose up -d --build
```

首次启动会自动创建 SQLite 数据库与表结构（无需手动初始化），随后访问：

**http://localhost:3000**

停止：`docker compose down`（数据保留在宿主机 `./data/glass.db`）。

### 方式二：本地 Node.js

要求 Node.js ≥ 18（better-sqlite3 安装时可能需要 Python3 与 C++ 编译工具）。

```bash
npm install
npm start
# => 彩绘玻璃拼片台已启动: http://localhost:3000
```

运行测试（几何核心单元测试）：

```bash
npm test
```

## 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 监听端口 |
| `DB_PATH` | `data/glass.db`（项目目录下） | SQLite 数据库文件路径；文件不存在时启动自动建表初始化 |
| `BENCH_PORT` | `3000` | 仅 Compose 使用：宿主机映射端口，如 `BENCH_PORT=8080 docker compose up -d` |

网页地址：启动后打开 **http://localhost:<端口>/**（默认 `http://localhost:3000`）。

## HTTP API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/projects` | 新建窗框 `{name, width, height}`（宽高须为正整数） |
| GET | `/api/projects` / `/api/projects/:pid` | 项目列表 / 项目详情（含草稿拼片） |
| POST | `/api/projects/:pid/pieces` | 新增拼片，校验失败返回 422 与错误位置 |
| PUT | `/api/projects/:pid/pieces/:id` | 修改拼片（顶点/颜色），同样校验 |
| DELETE | `/api/projects/:pid/pieces/:id` | 删除拼片 |
| GET | `/api/projects/:pid/gaps` | 当前草稿的缺口多边形列表 |
| POST | `/api/projects/:pid/publish` | 校验全覆盖后发布；有缺口返回 422 + 缺口 |
| GET | `/api/projects/:pid/publications` | 历史发布版本列表 |
| GET | `/api/projects/:pid/publications/:version` | 某历史版本的只读快照与铅条清单 |

## 项目结构

```
src/geometry.js   几何核心：简单多边形校验、片间冲突、缺口垂直条带分解、铅条支撑线归并
src/db.js         SQLite 访问层（projects / pieces / publications，启动自动建表）
src/server.js     Express API 与静态资源服务
public/           零构建前端（Canvas 编辑、错误位置标注、缺口显示、发布只读视图）
test/             几何核心单元测试（node --test）
Dockerfile        node:20-alpine，含 better-sqlite3 编译工具链
docker-compose.yml  端口 3000，数据卷 ./data
```

## 几何方法备注

- 全部输入坐标为整数毫米，故面积以 0.5 mm² 为最小单位，无亚毫米歧义。
- 片间判定区分穿越相交 / T 形接触 / 共线共边；对无穿越、无顶点在内部的
  凹多边形覆盖情形，使用“边中点向多边形内侧微偏移探针”补充检测。
- 缺口求解按所有顶点 x 坐标把窗框切成竖条带，在每条带内对射线穿过多边形的
  区间求并集，未覆盖区间还原为（可能含斜边的）四边形缺口。
